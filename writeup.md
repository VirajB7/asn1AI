## Q-4: Will Hill Climbing always find Solution?
<ul><li>No, it is not guaranteed that the hill-climbing algorithm will find a path. It is a local search algorithm that can get stuck in a local maxima. Hence, it is not guaranteed to find a path. </li><li>The algorithm relies on the heuristic function to make decisions about which neighbour to explore next, and it may choose a neighbour that does not lead to the goal but appears better according to the heuristic. If there is no path from the current position to the goal without going through blocked cells, the algorithm can get stuck.</li><li>To mitigate this issue, we can employ more advanced pathfinding algorithms like A* or Dijkstra's algorithm, which are guaranteed to find a solution if one exists and are often more suitable for grid-based pathfinding with obstacles. These algorithms use more sophisticated strategies to explore the search space and can handle a wider range of scenarios effectively.
</li></ul>

## Q-5: Non-convex obstacles result in a local maximum
<ul><li>Non -convex algorithms might pose challenge for hill-climbing algorithms, as it can create situations where it gets stuck at a local maximum due to the shape of the obstacle, it can see past through the obstacle. </li><li>	Going around the obstacle from any side have a cost, but the algorithm cannot see past the obstacle to evaluate the consequences of its choice, as a result it gets stuck into a local maximum. The algorithm might end up getting stuck in one of these local maxima, unable to find a path to the goal because it cannot anticipate the layout of the obstacle.
</li><li>In this scenario, a more sophisticated pathfinding algorithm like A* or Dijkstra's algorithm, which keeps track of visited cells and can backtrack, when necessary, is more likely to successfully find a path around the non-convex obstacle and reach the goal. These algorithms are not as prone to getting stuck in local maxima as simple hill-climbing algorithms.</li></ul>
